# HabitsTracker

Небольшое приложение для отслеживания привычек на SwiftUI.

Это один из моих первых учебных проектов. Делаю его, чтобы разобраться в SwiftUI, научиться работать с данными и постепенно привыкать к самостоятельной разработке приложений под iOS.

## Что уже работает

- Добавление и удаление привычек
- Возможность отмечать привычки выполненными
- Счётчик выполненных привычек и шкала прогресса
- Сохранение данных после закрытия приложения

## Что использовал

- Swift, SwiftUI
- `@State`, `Binding`, `ForEach`
- `Identifiable`, `UUID`
- `Codable`, `JSONEncoder`, `JSONDecoder`
- `UserDefaults`

Пока все данные хранятся локально через `UserDefaults`. Для небольшого учебного приложения этого достаточно.

## Как запустить

Нужно скачать проект, открыть `HabitsTracker.xcodeproj` в Xcode и запустить на симуляторе iPhone.
